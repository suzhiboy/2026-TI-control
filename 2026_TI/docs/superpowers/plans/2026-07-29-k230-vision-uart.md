# K230 Vision UART Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Send K230 steel-ball position in millimeters to MSPM0G3507 over UART and parse it without blocking the 10 ms control loop.

**Architecture:** K230 owns image detection and pixel-to-millimeter mapping. MSPM0 owns UART reception, line buffering, parsing, freshness timeout, and storage of the latest ball position. Stepper motor control is explicitly out of scope for this plan.

**Tech Stack:** CanMV K230 MicroPython, YOLO11 `libs.YOLO`, UART2 on K230 GPIO11/GPIO12, MSPM0 DriverLib UART0 on PA0/PA1, C host tests with MinGW.

---

### File Structure

- Create `k230/ball_position_uart.py`: CanMV script for YOLO detection, manual calibration, filtering, and UART output.
- Create `vision_uart.h`: MSPM0 public API and `VisionBallData` structure.
- Create `vision_uart.c`: MSPM0 UART line receiver and protocol parser.
- Create `tests/vision_uart_test.c`: host test for parser and line receiver behavior.
- Create `tests/k230_vision_static_check.py`: host check for K230 script constants and syntax.
- Modify `empty.c`: initialize `VisionUart`, poll it in the main loop, and show visual state on OLED.
- Modify `board_config.h`: add default vision UART macro fallbacks.
- Modify `empty.syscfg`: add UART0 named `VISION_UART` on PA0 TX / PA1 RX at 115200 baud.
