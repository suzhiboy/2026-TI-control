# 4 键菜单系统 — 按键使用说明

> 平台: MSPM0G3507 | 更新: 2026-07-29

---

## 一、按键与引脚

| 按键 | 引脚 | 标签 | 复用说明 |
|------|------|------|----------|
| K1 | PB12 | 上一个任务 | 独立 |
| K2 | PB13 | 下一个任务 | 与循迹 AD2 分时复用，RUNNING 时不响应 |
| K3 | PB2  | 调目标点 | 独立（原 IMU601 TX，已释放） |
| K4 | PB3  | 确认/启动 | 独立（原 IMU601 RX，已释放） |

## 二、按键操作定义

- **短按**：按下 < 1000ms
- **长按**：按下 ≥ 1000ms

---

## 三、各状态按键行为

### MENU（菜单选择态）

| 按键 | 操作 | 功能 |
|------|------|------|
| K1 (PB12) | 短按 | task_id++（下一个任务） |
| K1 (PB12) | 长按 | 确认任务，进入 READY |
| K2 (PB13) | 短按 | task_id--（上一个任务） |
| K2 (PB13) | 长按 | 恢复默认参数（task_id → T4，target_mm → 0） |
| K3 (PB2)  | 短按 | target_mm += 200（仅上电 2 秒内有效） |
| K4 (PB3)  | 短按 | target_mm -= 200（仅上电 2 秒内有效） |

### READY（就绪态）

| 按键 | 操作 | 功能 |
|------|------|------|
| K1 (PB12) | 短按 | 启动任务，进入 RUNNING |
| K2 (PB13) | 短按 | 放弃，回 MENU |
| K1 (PB12) | 长按 | 清零编码器 + 清零计时 + 清零摆杆角度零点 |

### RUNNING（运行态）

| 按键 | 操作 | 功能 |
|------|------|------|
| K1 (PB12) | 长按 | 急停，进入 STOPPED |
| K3 (PB2)  | 短按 | 人工中止，进入 STOPPED |
| K2 (PB13) | — | 不响应（此时 PB13 用作循迹 AD2） |

### STOPPED（停止态）

| 按键 | 操作 | 功能 |
|------|------|------|
| K1 (PB12) | 短按 | 重新进入 READY |
| K2 (PB13) | 短按 | 回 MENU |

### FAULT（故障态）

| 按键 | 操作 | 功能 |
|------|------|------|
| K1 (PB12) | 短按 | 清除故障，回 READY |
| K2 (PB13) | 长按 | 回 MENU |

---

## 四、任务列表

| task_id | 名称 | 说明 |
|---------|------|------|
| 2 | T2 一圈停车 | 循迹一圈后定点停车 |
| 3 | T3 静态球控 | 摆球到 target_mm 位置并稳住 |
| 4 | T4 A 到 B 稳中心 | 从 A 移动到 B，同时稳球在管道中心 |
| 5 | T5 一圈稳中心 | 行驶一圈，球稳在管道中心 |
| 6 | T6 一圈稳任意点 | 行驶一圈，球稳在 target_mm |

- 图传（任务 1）为系统常驻功能，上电即开，无需按键选择。
- target_mm 默认值：0 mm，步长 ±200 mm/次。
- 管道有效范围 ±120 mm，目标值超出自动限幅。

---

## 五、系统状态流转

```
上电 ──→ MENU
           │ K1长按
           ▼
         READY ←──────────────┐
           │ K1短按            │ K1短按(STOPPED) / K1短按(FAULT清故障)
           ▼                  │
         RUNNING ──→ STOPPED ─┘
           │ K1长按/K3短按     │ K2短按
           │                  ▼
           │                MENU
           │
           └── 故障发生 ──→ FAULT
                              │ K2长按
                              ▼
                            MENU
```

## 六、OLED 显示布局

```
┌─────────────────────┐
│ T4 A到B稳中心        │  Line 1: 当前任务名
│ target:   0 mm      │  Line 2: 目标点
│ [READY]             │  Line 3: 系统状态
│ Ball:   0 mm  C95%  │  Line 4: 小球坐标/传感器
└─────────────────────┘
```

状态标签：`[MENU]` `[READY]` `[RUNNING]` `[STOPPED]` `[FAULT]`

---

## 七、注意事项

1. **K2 分时复用**：PB13 在非 RUNNING 态是按键输入，RUNNING 态切回循迹 AD2。RUNNING 时的停止操作请使用 K1 长按（急停）或 K3 短按（中止）。
2. **上电 2 秒窗口**：仅在此期间 K3/K4 可调节 target_mm。超时后 K3/K4 在 MENU 态不再响应，直到进入 RUNNING 态 K3 才恢复（作为中止键）。
3. **target_mm 步长**：每次 ±200mm，水管理论范围 ±120mm（即 ±12cm），target_mm 自动 clamp 到有效范围。
4. **急停 vs 中止**：K1 长按急停和 K3 短按中止都进入 STOPPED 态，区别是急停是瞬时响应（长按 1000ms），中止是即时响应（短按）。
