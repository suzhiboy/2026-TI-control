  AUX    ─────── PB1  (GPIO 输入)

【重要: IOMUX 编号修正】
  之前的 board_config.h 中有 IOMUX 编号错误:
  ✗ BOARD_ATK_LORA_01_MD0_IOMUX = IOMUX_PINCM16  ← PINCM16 是 PB3 (IMU601 RX)!
  ✓ BOARD_ATK_LORA_01_MD0_IOMUX = IOMUX_PINCM12  ← PB0

  ✗ BOARD_ATK_LORA_01_AUX_IOMUX = IOMUX_PINCM17  ← PINCM17 是 PB4
  ✓ BOARD_ATK_LORA_01_AUX_IOMUX = IOMUX_PINCM13  ← PB1

  ✗ BOARD_ATK_LORA_01_UART_INST = UART2           ← UART2 被 VOFA 占用!
  ✓ BOARD_ATK_LORA_01_UART_INST = UART0           ← UART0 空闲, PA0/PA1 空闲

  ✗ BOARD_ATK_LORA_01_TIMER_INST = TIMA0          ← TIMA0 被控制循环占用!
  ✓ BOARD_ATK_LORA_01_TIMER_INST = TIMA1          ← TIMA1 空闲

  board_config.h 中已经修正, 不需要再手动修改.

================================================================================
  使用步骤
================================================================================

  1. 按上述步骤配置 SysConfig + 编译
  2. 在 main() 中:

  #include "atk_lora_01.h"

  // 初始化 LORA 模块
  if (atk_lora_01_init(115200) == ATK_LORA_01_EOK) {
      printf("LORA module init OK!\r\n");
  } else {
      printf("LORA module init FAILED!\r\n");
  }

  // 配置参数示例 (在配置模式下):
  atk_lora_01_enter_config();                    // 进入配置模式 (MD0=1)
  atk_lora_01_addr_config(0x0001);               // 设置地址
  atk_lora_01_tpower_config(ATK_LORA_01_TPOWER_20DBM);  // 最大功率
  atk_lora_01_wlrate_channel_config(23, ATK_LORA_01_WLRATE_19K2); // 信道23, 19.2Kbps
  atk_lora_01_echo_config(ATK_LORA_01_DISABLE);  // 关闭回显
  atk_lora_01_flash_config(ATK_LORA_01_ENABLE);  // 保存配置
  atk_lora_01_exit_config();                     // 退出配置模式 (MD0=0)

  // 发送数据 (透传模式):
  atk_lora_01_uart_printf("Hello LORA World!\r\n");

  // 接收数据 (在主循环中轮询):
  uint8_t *rx_buf = atk_lora_01_uart_rx_get_frame();
  if (rx_buf != NULL) {
      // 处理接收到的数据
      printf("LORA RX: %s\r\n", rx_buf);
      atk_lora_01_uart_rx_restart();  // 重新开始接收
  }

================================================================================
  AT 指令速查表
================================================================================

  指令              功能                    参数
  ───────────────────────────────────────────────────
  AT               通讯测试                无
  ATE0/ATE1        关闭/开启回显           0/1
  AT+RESET         软件复位                无
  AT+FLASH=0/1     不保存/保存配置         0/1
  AT+DEFAULT       恢复出厂设置            无
  AT+ADDR=XX,XX    设置设备地址            2字节十六进制
  AT+TPOWER=0~3    发射功率                0:11dBm 1:14dBm 2:17dBm 3:20dBm
  AT+CWMODE=0~3    工作模式                0:一般 1:唤醒 2:省电 3:信号强度
  AT+TMODE=0~1     传输模式                0:透传 1:定点
  AT+WLRATE=C,R    无线速率和信道          C:0~83 R:0~5
  AT+WLTIME=0~1    唤醒时间                0:1秒 1:2秒
  AT+UART=B,P      串口参数                B:0~7(波特率) P:0~2(校验)

================================================================================
  注意事项
================================================================================

  1. 模块出厂默认: 地址=0x0000, 信道=23, 速率=19.2Kbps, 功率=20dBm, 115200 8N1
  2. 两个模块要通讯, 必须信道一致, 透传模式地址无关
  3. AUX 引脚指示模块状态: 低电平=空闲, 高电平=忙碌
  4. 发送数据前建议检查 AUX 是否空闲
  5. 初始化时 MCU 端和 LORA 模块端的波特率必须一致
